## Locked rules (do not change without the user)

- Styles only: every fill, stroke and text is bound to a paint or text style. Never raw hex values.
- Poppins only (Inter only in image placeholders). Weights 200/300/400/600 — never Bold 700.
- Headlines pair two weights at one size: base style on the whole text, the matching `… Keyword` style (SemiBold) on the last words.
- Orange is never text on Primary/Blue or Dark Charcoal. Modules sit on white; only CTA banners, the footer and the announcement bar carry colour. Green is for sustainability content only. Teal only inside the Infinite Facade® logo. Black, light gray and #241F20 are retired.
- Radius 0 except circles, pagination dots and the 26×6 active pill.
- Every page section is a library instance or a frame named `Page-specific / …`. Desktop and Mobile pages have the same sections in the same order.
- Footer and Brand Sign-off Band instances keep the component's own copy on every page (the mobile components are condensed on purpose — never push the source page's footer copy into them).
- Page copy is FPO (placement copy): when copy doesn't fit a component, merge body paragraphs or trim, and record it in the page's Build notes panel. Don't ask the user about copy fit — decide and note it.
- Follow the source HTML where it differs from the README, and flag the difference on the cover (`00 · Cover` → Page order & flags frame).
- Don't detach instances. Fix things in the component when they should apply everywhere, and keep Desktop and Mobile variants in step.
- The user saves versions and publishes the library manually (the plugin API can't). Remind them after significant changes.

## Figma Plugin API gotchas learned on this file

- Setting font/size/case after `setTextStyleIdAsync` detaches the style. Setting `.characters` on a mixed-style text flattens keyword runs — re-apply the Keyword style with `setRangeTextStyleIdAsync`.
- Overriding a run's weight by hand detaches it from its style; use the Keyword style instead. `tooling/figma-scripts/rebind.js` repairs detached runs (nearest style: size ±2, weight ±1 step, same case).
- `use_figma` hides invisible instance sublayers from the API (`figma.skipInvisibleInstanceChildren`). Set it to `false` when you need hidden layers. Layer-count differences between an instance and its main component are not staleness.
- `setProperties` on an instance invalidates handles to its sublayers — look nodes up again by id afterwards.
- One `setCurrentPageAsync` per call; use `page.loadAsync()` for other pages. Failed calls roll back. The code limit is 50 KB and responses are truncated around 20 KB — return compact data.
- `setFileThumbnailNodeAsync` and version saving aren't supported.
- Frames with aspect ratio locked resist `resize` — call `unlockAspectRatio()` and clear padding first.
- Overflow checks must include text spilling out of fixed-height *non-clipping* parents, not just clipped text (`tooling/figma-scripts/overlap-scan.js`).

## Stored code inside the Figma file

`figma.root.getSharedPluginData('cpbuild', key)` holds reusable scripts, loaded with `eval`:

| key | what | repo copy |
|---|---|---|
| `lib` | component converter (plan → Figma nodes) | `tooling/lib.js` |
| `pagert` | page-builder runtime | `tooling/pages/runtime.js` (store with `pages/mkstore.js`) |
| `accept` | acceptance checks | `tooling/figma-scripts/acceptance.js` |
| `rebind` | nearest-style rebind | `tooling/figma-scripts/rebind.js` |
| `guidelib` | guide/cover layout helpers | `tooling/figma-scripts/guide-lib.js` |
| `dict_desk`, `dict_mob` | shared text dictionaries used by page batches | regenerated by `tooling/pages/batch.js` |
| `gradmap` | gradient signature → paint style id | — |

Keep the repo copy and the stored copy in sync; prefer small in-place string patches of the stored copy over re-sending the whole thing.
