Mobile Kit

Every canonical module at the Mobile breakpoint (390 frame, 20px margins, Elementor Mobile ≤767). Each artboard's label is its Figma name: import with html.to.design, then combine each Desktop/Mobile pair into one component set with a Breakpoint property. Tablet (768–1024) follows the rules in the documentation and has no separate artboards.
