## NOT INCLUDED
- **Clark Pacific Figma 2.5 Guide.pdf.** I can't render a PDF to a file from this environment. To make it: open `Clark Pacific Figma 2.5 Guide.dc.html` in Chrome → ⌘P → Destination “Save as PDF”, Margins “None”/default, Background graphics ON. The page is a print-ready doc-page (flowing, the checklist starts on a new page).
- **Font files (Poppins, Inter).** Not in the project; every HTML file loads them from Google Fonts (`fonts.googleapis.com`). Offline, text falls back to system fonts. Install Poppins 200/300/400/600 and Inter 400/500/600 locally, or be online, when rendering.
- **A Figma file.** None was created (no Figma write access here). The 45 components exist only as HTML.
- **Mobile variants / sketches of the 45.** None were made. Desktop only.
- **`CLAUDE.md` under its own name.** The file name is reserved here, so the project-rules file is included as `_working/PROJECT-RULES -CLAUDE.md copy-.md`. The contents are identical.
- **Real photography.** None exists; every image is a placeholder (listed per component below).

## 3. Interactions (the 11 interactive components)
Written as Figma prototype specs. “Live in source” = working in the .dc.html (click it in a browser to see it). “Static in source” = the library frame has no working state; the behaviour is the specified intent only, and any timing marked *proposed* is mine, not from source. Global hovers (all components): text-link bar fills L→R to label width, Accent/Orange, 400ms ease; Primary button darkens to `#003D84`; outlined buttons get 12% fill of the outline colour.

### 2.5 / Cards / Insights feed · Filterable — `a25-cards-insights-feed-filterable`
**Trigger:** click a filter chip (All · Articles · Podcasts · Webinars). **States:** 4 (`insightFilter` = all | article | podcast | webinar); default **All**. **Layers that change:** active chip label colour → Text/Dark Charcoal `#52565A` (inactive chips → Neutral/Mid Gray `#7F8A92`); the active-indicator layer under the chip is visible only on the active chip; the card grid shows only cards of that type (All shows every card). **Timing:** instant in source (no CSS transition); for Figma use Smart animate 200ms ease-out between the 4 variants. Model as a component set `Filter = All|Article|Podcast|Webinar`, each chip On Click → Change to its variant.

### 2.5 / Carousel / Image + content · 3-up — `a25-carousel-image-content-3-up`
**Trigger:** click ‹ (prev) or › (next) arrow. **Behaviour:** pages by **3 cards** (index += 3 / −= 3), clamped — no loop. 6 items in source → pages start at 0, 3, …, 3. **Layers that change:** the three visible cards (image, type · date, title, body, accent bar colour); prev arrow opacity **0.22** on the first page / 1 otherwise; next arrow opacity **0.22** on the last page / 1 otherwise. **Timing:** instant in source; Figma: Smart animate / slide-left 300ms ease-out. Variants `Page = 1..n`. Mobile: swipe row + dots.

### 2.5 / Carousel / Image + content · 4-up — `a25-carousel-image-content-4-up`
Same as 3-up but pages by **4 cards**, clamped, no loop (6 items → last page starts at 2). Arrow opacity 0.22 at the ends / 1 otherwise. Instant in source; Figma Smart animate 300ms ease-out.

### 2.5 / Carousel / Product highlights — `a25-carousel-product-highlights`
**Trigger:** click ‹ / ›, or click a dot. **States:** 5 slides (`carousel` 0–4), default slide 1. ‹ / › **wrap around** (loop: 5 → 1, 1 → 5). Dot i → slide i. **Layers that change:** the render placeholder label (“PRODUCT RENDER · n / 5”), counter text “n / 5”, eyebrow text and body text swap to that slide's copy; active dot class `vt-dot vt-active`. **Dot spec (source CSS):** inactive 8×8 circle, fill `rgba(0,0,0,0.18)`; active 26×8, radius 3, fill Accent/Orange `#FF8600`; transition background/width/radius **300ms ease**. Note README says the pill is 26×6 — source renders 8px tall (see Differences). Figma: variants `Slide = 1..5`, Smart animate 300ms ease.

### 2.5 / Project Detail / Spec panel — `a25-project-detail-spec-panel`
**Static in source — behaviour is specified only.** Intended: click a thumbnail → main 4:3 photo swaps to that image (Smart animate dissolve 200ms, proposed); active thumbnail full opacity. Click the “+6” tile → opens a full-screen lightbox gallery (overlay, Open overlay / Close on click outside or ✕). No timings in source.

### 2.5 / Careers / Open positions list — `a25-careers-open-positions-list`
**Static in source — behaviour is specified only.** Intended: click a department tab (All · Engineering · Manufacturing · …) → the job list filters to that department; active tab gets the underline indicator bar, others none. Each job row is a link out to the ATS posting (hover: title → Orange, proposed). No timings in source; propose instant filter, 200ms indicator slide.

### 2.5 / Insights / Filter bar — `a25-insights-filter-bar`
**Static in source — behaviour is specified only.** Intended: click a tab (All · Data Centers · Facades · Parking · …) → list below filters; the active tab text is `#52565A` with a **2px bottom bar**; inactive tabs muted. Propose indicator slide 200ms ease-out.

### 2.5 / Insights / Content archive · Paginated — `a25-insights-content-archive-paginated`
**Live in source.** **Triggers:** click a type chip (All · Articles · News · Webinars · Podcasts · Resources); click a page number; click ‹ Prev / Next ›. **State:** `archiveFilter` (default all) + `archivePage` (default 1). **Chip states (verbatim):** active bg `#52565A`, text `#FFFFFF`, border `#52565A`; inactive bg `#F0F0F0`, text `#52565A`, border `#DEDFE0`. Selecting a chip resets to page 1. **5 items per page.** Result count text updates to the filtered total. **Page numbers:** active bg `#52565A` / text `#FFFFFF`; inactive transparent / `#52565A`. Prev opacity **0.28** on page 1, Next opacity **0.28** on the last page, else 1. Instant (no transition). Search field is visual only in source (spec: narrows as you type).

**Live in source.** Two chip rows that **combine (AND)**: Product Type (All Projects · Data Centers · Building Envelope · Parking · Structural) and Region (All · NorCal · SoCal · PNW). ## 8. Kim's workflow (as given to her in the Guide)
1. **Save a backup version.** In your Clark Pacific file: File → Save to version history, title **Before 2.5**, Save.
2. **Add a new page for them** named **Components · 2.5 Additions**. Don't paste onto your existing Components page.
3. **Copy a component from 2.5.** Open *Clark Pacific 2.5 Additions*, select the whole frame (use the Layers name if a click only selects a child), then ⌘C. Shift-click to copy a batch of about five.
4. **Paste onto the new page:** check that page is highlighted, then ⌘V.
5. **Make it a component:** right-click → Create component (⌥⌘K). It turns purple. Check the name starts with **2.5 /**. For several at once use *Create multiple components*, never *Create component set*.
6. **Bring the dev notes along:** paste each yellow card beside its component as a plain frame, not a component.
7. **Use one on a page:** Assets → search “2.5” → drag it onto the blue line between sections. **Don't use Swap Instance** on sections you've already edited. It replaces the section and loses your text and photo-label edits. Drag the new one in, copy your text across, then delete the old one.
8. **Do and don't.**
   - Paste only onto the 2.5 page.
   - Keep the 2.5 / names.
   - Don't combine as variants.
   - Don't resize, re-layout or rename existing components.
   - Don't detach instances.
   - Don't make the notes into components.
9. **If something goes wrong:** ⌘Z. For anything bigger, File → Show version history → **Before 2.5** → ••• → Restore this version. Then message Nathan.
