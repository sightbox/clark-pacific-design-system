## Typography

**Fonts:** Poppins (all panel content) + Inter (doc chrome, style-guide labels, annotation text).
**Google Fonts import:** `Poppins:wght@200;300;400;600;700` and `Inter:wght@400;500;600`.

### Headline composition rule
Every section headline pairs a **light/regular weight** (context) with a **SemiBold weight** (emphasis keyword) at the **same size tier**. The keyword always lands at or near the end. Global elements and headlines use **SemiBold (600) as the heavy weight — never Bold (700)**.

- **Type caps at Dark Gray `#52565A` (locked June 2026).** ALL headlines & body type — every panel, Infinite Facade® included — use Dark Charcoal `#52565A` as the darkest value. INF Black `#241F20` is retired.
- **On light panels:** keyword is `font-weight: 600`, color `#52565A` — no orange, no teal.
- **On dark/CTA panels:** keyword is `font-weight: 600`, color `#FFFFFF` — **no orange type on dark surfaces** (Angela contrast note, Sept 2026). Orange remains available on dark as a graphic accent only (3px bars, tab indicators, pagination dots).
- **On sustainability panels:** keyword may be `#009663` (Green).
- **Infinite Facade® panels** follow the standard rules above — the only teal element is the product wordmark/logo (`#00ADC8`).

All headings are `text-transform: uppercase`. Letter-spacing: `-0.03em` to `-0.04em`.

## Layout patterns (four structures)

1. **One Column** — full-width single zone. Full-bleed photo or CTA banner.
2. **Two Column 50/50** — equal halves, image + text. Flip left↔right for variety.
3. **Two Column 40/60** — narrow headline left, wide body/content right (or reversed).
4. **Three Column** — equal zones, card anatomy: Image → Orange 3px accent bar → Headline → Body → CTA + metadata.
5. **Icon Rows** — 2-up (full-width) or 3-up (inside a right column). Icon circle + subheading + body.

**Page rhythm (July 2026):** ALL modules sit on White — the White ↔ BG Alt alternation and the dark stats band are retired. CTA banners / decision panels may use Blue (`#004A9F`) or Dark Charcoal; the **global footer stays Dark Charcoal (`#52565A`)** — the only sanctioned dark surfaces.

**Hybrid max-width layout (locked June 2026):** every page section is two layers — a **full-bleed background** div (background color/photo spans any browser width) wrapping a **capped content** div (`max-width: 1440px; margin: 0 auto; padding: NNpx 72px`). Backgrounds run edge-to-edge; content centers within 1440px so headlines/grids never stretch on wide monitors. Exceptions that stay full-bleed: the sticky nav, the footer (own structure), and hero *photo* placeholder areas with no text content. Applied across all 38 page files via scripted transform.

## Button system

| Type | Style |
|---|---|
| Primary | Blue `#004899` fill, white text, no border |
| Secondary | 1.5px `#52565A` outline, dark text |
| Text link | Label + accent underline bar — see hover rule below |
| On-dark secondary | 1.5px `rgba(255,255,255,0.55)` outline, white text |

All button labels: Poppins SemiBold 14px UPPERCASE.

**Text-link (`cp-textlink`) rules locked in:**
- The track (faint underline) width **= the text label width** (achieved with `display: inline-block` on the wrapper). The track never extends past the label.
- Default: bar starts at width 0. **On hover** the bar animates left→right to fill the full track width and transitions to color (0.4s ease).
- Default bar color is faint (`rgba(0,0,0,0.12)` on light); hover color is **Orange `#FF8600`**.
- Variants: `cp-textlink-green` (hover → Green `#009663`, sustainability only), `cp-textlink-blue` (hover → Blue `#004A9F`), `cp-textlink-white` (white text + faint white track, hover → Orange, for dark surfaces). The `cp-textlink-teal` variant is **retired** — Infinite Facade® text-links use the default Orange hover like every other product page.
- CTA top margin (both text links AND solid buttons): **`34px`**.
- **Card Read More rule (July 2026):** inside cards (insights feed, image+content carousels, sub-category cards) the track spans the **full column width** for structure, with a short 32–44px Blue/Orange accent bar under the label that fills the track on hover. Label-width tracks remain the rule for standalone text links in content panels.

**Spacing rules locked in (content panels):**
- Headline → paragraph gap: **`20px`**
- Accent bar / eyebrow → headline gap: **`20px`**
- Paragraph → CTA gap: **`34px`**
