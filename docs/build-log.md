# Build log

How the Figma file was built (2026-09-23 → 2026-09-24), the decisions taken, and what was learned. Built with Claude Code driving the Figma Plugin API through the Figma MCP `use_figma` tool.

## 1. Styles and components (02 · Components)

- The kit HTML (`handoff/source/kits/`) was rendered in headless Chrome (`tooling/extract.js`) and each artboard's computed layout dumped to JSON. `planner.js` turned those trees into compact build plans (auto layout, spacers, style binding, primitive instance matching); `compbuild.js` generated `use_figma` calls that ran the converter library (`lib.js`, stored in the file as `cpbuild/lib`).
- 42 component sets were built in 9 groups, each with Desktop and Mobile variants; repeating items (FAQ Item, Icon Grid Item, cards, Stat, Process Step) are their own components.
- **Source over README** where they differ (button padding 16×32, text-link track 3px), with the difference flagged.
- Off-token source colours became `Flagged/*` styles instead of being silently remapped. Logo artwork keeps its own colours.
- Display/Heading texts are not text properties (binding would flatten the SemiBold keyword run); other strings are, named by role and merged across variants where the copy is equivalent.
- **Bug found and fixed:** the builder re-applied font/size/case after `setTextStyleIdAsync`, detaching every style. Fixed, then texts were bound to the nearest style (size ±2, weight ±1 step, same case). 25 + 10 + 3 styles were added for off-scale roles, all flagged in their descriptions.

## 2. Foundations (01 · Foundations)

Overview, Color, Typography, Added styles, Layout, Buttons & links — generated by `tooling/found/gen.js`. #241F20 was found to be retired and removed.

## 3. Pages (03 · Pages Desktop / 04 · Pages Mobile)

- The user imported all 76 source pages with html.to.design; `tooling/align/core.js` aligned those imports to the system (paints and text bound, tag pills hidden, stacked fills collapsed, retired colours remapped). They were kept as **05/06 · Page References**.
- Pages were then rebuilt from library instances:
  1. `pagex.js` splits each page at its `data-component` markers into sections.
  2. `match.js` aligns each section's text sequence (by role: head / label / link / title / body) against every candidate variant (Needleman-Wunsch) and picks the best fit; tag-named Hero types are forced, and Announcement Bar / Header overlays are split out when a variant lacks them.
  3. `pages/batch.js` packs page specs into `use_figma` calls; `pages/runtime.js` (stored as `cpbuild/pagert`) builds each page: one instance per section, copy filled by alignment, unused layers or `Show item N` hidden, keyword weights and run sizes applied, icons swapped, and a Build notes panel written.
- **FPO copy policy** (user decision): extra body paragraphs merge into the nearest body; other copy with no slot is trimmed and listed in Build notes.
- **Quality gates** fall back to a `Page-specific /` copy of the reference section when a filled text overflows, or when the lost copy includes a heading, two or more titles, or five or more strings (Hero exempt).
- Result: Desktop 266 instances / 69 page-specific; Mobile 279 / 107. Desktop and Mobile section counts match on all 38 pairs.

## 4. Prototype, cover, guide

- Interactions on components: Button / Text Link / Card / Leadership hovers, FAQ toggle, Header mega-menu and mobile menu, Image-as-button hover (new State property on Canonical Card), Image Gallery and Video Module carousels (new Slide property).
- 00 · Cover (cover + page order & flags + acceptance results) and 00 · Guide (five-chapter walkthrough) were built with `tooling/figma-scripts/guide-lib.js`.

## 5. Acceptance and review fixes

- `figma-scripts/acceptance.js` runs the README checks. `figma-scripts/rebind.js` rebound ~900 detached heading runs (mostly keyword runs whose weight had been overridden). Black photo scrims became six Dark Charcoal gradient paint styles.
- Review fixes after user feedback: stats rows hand-filled; Header Over photo made transparent (it hid content under an opaque demo photo); mobile duplicate announcement strip hidden; editorial heroes corrected; mobile import glitches (Careers cards, podcast guest block and episode rows, card padding) rebuilt; text columns in Video Module / System Overview changed to hug their copy. Final overlap scan: 0 overlaps, 0 spills.

## Lessons

- Never set text properties after applying a text style; never hand-override a run's weight — use the Keyword style.
- Setting `.characters` on a mixed-style text flattens it to the first run's style.
- `use_figma` skips invisible instance children by default — count mismatches against the main component are not staleness.
- An overflow check that only looks at clipping frames misses text spilling out of fixed-height, non-clipping containers.
- Imported (html.to.design) frames bake hard line breaks and fixed widths into text; clean them before reusing the layers.
- Plugin API cannot save versions, publish libraries or set the file thumbnail — those are manual.
